# 맥락 — 알수록 보이는 뉴스

뉴스 제목만 훑는 대신, 이해에 필요한 배경지식을 단계적으로 읽을 수 있게 만든 뉴스 리더입니다.

## 현재 구조
- Next.js App Router
- SBS 공식 RSS + BBC RSS + Google News 기반 CNN/MBC 피드
- `revalidate = 900`으로 최대 15분 캐시
- 기사별 출처·발행 시간·원문 링크
- 한눈에 → 맥락 보기 → 깊이 이해의 3단계 설명

## 업데이트 방식
Vercel에서 페이지/데이터 캐시가 15분을 넘기면 다음 요청에서 최신 피드를 다시 가져옵니다. 즉, 별도의 유료 Cron 없이도 방문 시점 기준으로 최근 데이터를 유지하는 MVP 구조입니다.

## 주의
RSS 및 기사 메타데이터의 이용 조건은 각 제공처 정책을 따릅니다. 상업적 사용 전에는 반드시 해당 언론사의 이용 조건을 확인하세요.
